# pct-split

按占比把一个总量拆成各分项，输出可直接粘贴进飞书的纯文本算式。供 Claude Code 作为 skill 使用。

## 这个 skill 做什么

日常场景：截一张看板图——比如 AI token 用量总数 + Claude / Codex / WorkBuddy 各自百分比——需要把每项的绝对值算出来，发给同事。

本 skill 负责这段换算，并把结果固定成一种便于转发的格式：

```
Claude：2,572,165,448*72.59%=1,867,134,899
Codex：2,572,165,448*15.49%=398,428,428
WorkBuddy：2,572,165,448*11.91%=306,344,905
```

也支持反过来：给各分项绝对值，算占比，写成 `名称：分项/总数=百分比`。

## 为什么是这个格式

- **写全算式**（总数\*百分比=结果），对方一眼看出数是怎么来的，不用回头问。
- **纯文本、不用 markdown 表格**，表格粘进飞书会散架。
- **中文全角冒号 + 千分位逗号**，跟飞书里的中文语境一致。
- **只给要的那几项**，看板上的"模型数""折合费用"没被要求就不塞，否则对方还得手动删。
- **名称写法沿用来源截图**（`WorkBuddy` 不改成全大写），便于跟原图对上。
- **四舍五入差额单独说**，不混进算式行里——用户复制那几行时不会带上多余的话。

## 舍入差额的处理

看板上的百分比通常已经四舍五入，合计常是 99.99% 或 100.01%，各项相加跟总数对不上。脚本会把差额算出来，走 stderr 单独提示，不污染正文：

```
[核对] 占比合计 99.99%，各项相加 2,571,908,232，与总数差 257,216
```

差额大到不像舍入误差（超过总数 1%），通常是漏项或读错数，先回头核对再发。

## 用法

```bash
python3 scripts/split_by_pct.py --total 2572165448 "Claude=72.59" "Codex=15.49" "WorkBuddy=11.91"
```

| 参数 | 说明 |
| --- | --- |
| `--total` | 总量，可带千分位逗号、`$`、`%`，脚本自动清洗 |
| `--decimals` | 每项结果保留几位小数。`0`（默认）用于 token、人次等计数类；`2` 用于金额 |
| `名称=百分比` | 位置参数，可给多个，百分比写数字即可 |

金额示例：

```bash
python3 scripts/split_by_pct.py --total '$1,165.89' --decimals 2 "Claude=72.59" "Codex=15.49" "WorkBuddy=11.91"
```

计算用 Python `Decimal`（ROUND_HALF_UP），不走浮点，避免十亿级数字上的精度漂移。

## 使用前提

- Python 3（仅用标准库，无需安装依赖）
- 装在 `~/.claude/skills/pct-split/` 下即可被 Claude Code 识别

## 边界

不负责金融行情数据查询（走 `wind-mcp-skill` / `ifind-finance-data`），不负责作图。算完要发飞书的，走 `lark-im`，且发送前需明确确认收件人和内容。
